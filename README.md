# Damian Valencia — engineering portfolio

Published at https://vision1224.github.io/ through GitHub Pages.

Static, dependency-free portfolio: semantic HTML, responsive CSS, native light/dark preferences and no JavaScript required. The landing page prioritizes professional impact, selected engineering work, experience, technical toolkit and hiring/contact information. Current private prototypes are clearly distinguished from public repositories and planned capabilities.

## Edit and preview

- `index.html`: content, links, metadata and structured profile.
- `assets/css/site.css`: visual system, responsive layout, accessibility styles.
- Existing `assets/js/site.js` is retained for history but is no longer loaded.

Run `python -m http.server 8000` and open http://localhost:8000.

## Release review

Check resume dates and metric wording against the approved facts file. Test desktop and narrow mobile layouts, keyboard navigation, contrast, light and dark themes, contact links and project links. No private code, personal documents or application records belong here.
